# Privacy And Sanitization

This repository is a clean-room portfolio representation of a private workplace project. It was intentionally assembled without copying the production package into Git history.

## Excluded Material

- Employer and facility names
- Employee, manager, and safety-contact identities
- Email addresses and phone numbers
- Microsoft tenant and SharePoint site URLs
- SharePoint list, environment, connector, and connection identifiers
- Internal policy files, training materials, and operating procedures
- Employee certification records
- Production prompts containing organization-specific processes
- Branded icons and other proprietary assets

## Included Material

- Generic architectural patterns
- Representative configuration with explicit `YOUR_*` placeholders
- Synthetic certification records for schema illustration
- Public OSHA links
- General safety-assistant governance principles

## Before Reusing

Run a secret scanner, review Git history, and inspect every document and image before publishing a derivative. Deleted files can remain in Git history, which is why a fresh repository history is preferred for sanitized releases.
